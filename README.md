# magento2-product-attachments-extension
Magento 2 Product Attachments Extension

Magento 2 Product Attachments is a lightweight and flexible extension that allows store owners to upload files and attach them to product pages. It helps merchants provide important documents such as manuals, datasheets, certificates, and guides—improving customer trust, reducing support requests, and increasing conversion rates.

This extension is ideal for B2B and B2C Magento stores that require downloadable product documentation.

Key Features

✅ Fully compatible with Magento 2

✅ Easy attachment management from the Admin Panel

✅ Display product attachments in a dedicated Attachments tab

✅ Supports unlimited file uploads per product

✅ Tracks attachment download count automatically

✅ SEO-friendly and performance-optimized

✅ Works with custom and Luma-based themes

Admin Configuration

Configuration Path:

Stores → Configuration → Product Attachments

Available Settings

Enable Product Attachments
Enable or disable the extension globally.

Product Attachments Tab Title
Customize the tab title displayed on the product page.

Product Attachments Heading
Set a custom heading text for the attachments section.

Display File Size (Frontend)
Show or hide attachment file size (Yes / No).

Display Download Count (Frontend)
Show or hide total number of downloads (Yes / No).


Installation

Run the following commands from your Magento root directory:

bin/magento module:enable Octocub_ProductAttachments

bin/magento setup:upgrade

bin/magento cache:flush

bin/magento setup:di:compile

Compatibility

Magento Open Source 2.4.x

Adobe Commerce supported

Compatible with most Magento themes

Works with multi-store setups
